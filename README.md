An ultra-modern, interactive, and gamified exam preparation portal designed specifically for elementary, middle, and high school students (**Grades 1 to 10**) competing in Science Olympiad Foundation (SOF) examinations worldwide.

---

## 💡 The Idea: Why OlympiadQuest?

### The Challenge
Every year, millions of students across the globe participate in prestigious SOF Olympiad examinations. However, young learners often encounter major hurdles:
1. **High-Stress Exam Formats**: The jump from school textbooks to multi-step Olympiad Higher Order Thinking Skills (**HOTS / Achiever's Section**) can be intimidating.
2. **Lack of Socratic Feedback**: When students get stuck, conventional books simply print the final answer without guiding the student through the problem-solving intuition.
3. **Exam-Day Anxiety & Bubble Sheet Mistakes**: Many younger students struggle with time management, rough-work space, and filling physical OMR bubble answer sheets.
4. **Expensive Coaching Barriers**: Access to high-quality Olympiad coaching is often expensive and geographically limited.

### Our Solution
**OlympiadQuest** transforms Olympiad preparation into an exciting, space-themed learning quest:
- **Zero-Latency Instant Learning**: Hundreds of high-quality questions, chapter guides, 2020–2025 previous year papers, and formula sheets are pre-loaded to work instantly offline.
- **On-Demand Dual-Model AI Mentorship**: Integrates **OpenAI** (`gpt-5.4-mini` / `gpt-5.4-nano`) as primary and **Google Gemini** (`gemini-flash-latest` / `gemini-flash-lite-latest`) as automatic fallback to provide a **3-Step Socratic Hint Ladder** and infinite dynamic question generation.
- **True-to-Life Simulation**: Features authentic 60-minute timed mock tests, digital rough-work scratchpads, and printable OMR bubble worksheets for physical practice.

### 2. 🎒 Grade-Wise Hub (Grades 1 to 10)
- **Tailored UI Themes & Avatars**: Automatically adapts typography, button sizes, and guidance tone from junior explorers (Grades 1–4) to senior scholars (Grades 5–10).
- **Chapter Explorer**: Visual breakdown of high-frequency topics, common traps, and memory mnemonics.
- **One-Click Chapter Drills**: Launch focused 10–15 question drills on any specific syllabus chapter.

---

### 3. ⏱️ Authentic SOF Mock Test Simulator
- **Real 4-Section Pattern**:
  - Section 1: Logical & Analytical Reasoning (10 Qs)
  - Section 2: Mathematical / Science / Subject Core (10–25 Qs)
  - Section 3: Everyday Applications (10 Qs)
  - Section 4: **Achiever's Section (HOTS)** with **2x / 3x Score Weightage**!
- **Live Countdown Timer**: Visual and synthesized audio ticking alerts during the final minute.
- **Interactive Scratchpad Canvas**: Built-in digital rough sheet with pen, eraser, and color picker for geometry sketches and calculations.
- **Question Navigator Palette**: Color-coded tracking for Answered (Green), Flagged for Review (Purple), and Unvisited (Slate).
- **Text-to-Speech Voice Reader**: Kid-friendly speech synthesizer that reads questions aloud.

### 5. ⚡ SOF 2nd Level (Round 2) Qualifier Accelerator

### 6. 🤖 Dual-Engine AI Olympiad Coach
- **Dual-Model Failover Router**:
  - Primary: **OpenAI** (`gpt-5.4-mini`, `gpt-5.4-nano`, `gpt-4o-mini`, customizable)
  - Backup: **Google Gemini** (`gemini-flash-latest`, `gemini-flash-lite-latest`, customizable)
  - Smart Offline Fallback: High-fidelity built-in engine if API keys are not entered.
- **3-Step Socratic Hint Ladder**:
  1. *Hint 1 (Clue)*: Points out the core principle without giving away the answer.
  2. *Hint 2 (Guiding Step)*: Gives the mathematical step or formula setup.
  3. *Hint 3 (Near Solution)*: Walks through the near-complete solution.
- **Infinite AI Question Generator**: Generates brand new custom Olympiad questions dynamically on any topic or grade level.

## 🛠️ Tech Stack & Architecture

- **Frontend**: React 18 + TypeScript + Vite
- **Styling**: Tailwind CSS + Glassmorphism & Space Theme
- **Math Rendering**: KaTeX (`katex`)
- **Visuals & Icons**: Lucide React + Canvas Confetti (`canvas-confetti`)
- **Audio Engine**: Web Audio API (Tone Synthesizer) + Web SpeechSynthesis
- **AI Service Layer**: Custom Failover Router (OpenAI API $\leftrightarrow$ Google Gemini API $\leftrightarrow$ Offline Engine)
- **Deployment**: Vercel (`vercel.json` SPA routing configured)

## 🚀 Quick Start Guide

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/kprsnt2/Olympiad.git
cd Olympiad
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open **`http://localhost:3000`** in your browser.

### 3. Build for Production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel in 1 Click

1. Push your changes to GitHub (`git push origin main`).
2. Go to **[vercel.com](https://vercel.com)** and click **"Add New..." $\rightarrow$ "Project"**.
3. Import the repository **`kprsnt2/Olympiad`**.
4. Vercel automatically detects the Vite configuration:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy**! Your site is live with a free SSL certificate.
